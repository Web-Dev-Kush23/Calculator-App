# 🧮 Calculator App (Next.js)

A simple and responsive Calculator Application built using **Next.js**.  
This app performs basic arithmetic operations with a clean and modern user interface.

---

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear Screen Functionality
- 📱 Responsive Design
- ⚡ Fast Performance with Next.js

---

## 🛠️ Tech Stack

- **Next.js**
- **React.js**
- **JavaScript**
- **CSS / Tailwind CSS**

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/calculator-app.git
```

### 2️⃣ Navigate to Project Directory

```bash
cd calculator-app
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

The application will start on:

```bash
http://localhost:3000
```
